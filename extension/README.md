# Alibasa 1.13.1

Lightweight Chrome page and selection translation using Bing / Microsoft or Google.

Extract the Chrome ZIP, replace the existing extension files, reload the extension in chrome://extensions, and refresh your webpages. Select the engine, languages and other preferences in the main popup. Changes save automatically. Overlay Settings opens that same popup.

The overlay uses an icon-only button with 35% idle opacity and full opacity on hover, keyboard focus or open menu. Its menu shows source → target languages at the bottom-left, with Stop, Restore, Settings and Hide overlay actions. Hide lasts until the page is refreshed.

Choose System, Light or Dark in the main menu. System follows your device appearance.

Bilingual mode highlights paragraph translations. Compact controls, navigation, tables and constrained elements show translations in hover tooltips to preserve their layout.

Use Hide overlay / Show overlay in the main menu to change visibility on the current webpage without refreshing.
